# Maser Global Impex

Static website for Maser Global Impex — chemicals, commodities, and food & agri trade. Vancouver, BC, Canada.

- `index.html` — main site (Home, About, Products, Services, Markets, FAQ, Contact)
- `food/index.html` — Food & Agri Commodities page, served at `/food/` (share this link with food buyers)

No build step. Deploy the folder as-is to GitHub Pages, Cloudflare Pages or Netlify.

To change the WhatsApp number, edit `WA_NUMBER` and `WA_DISPLAY` near the top of the script in both HTML files.
